# Agentes MK — instruções do projeto

Este repositório adota o **Protocolo MK de Qualidade** mantido em `dudusltnmendes-star/alpha`, no arquivo `PROTOCOLO_MK_QUALIDADE.md`.

1. Antes de trabalhar, consulte a cópia local em `docs/PROTOCOLO_MK_QUALIDADE.md` (quando disponível).
2. Para verificar a versão mais recente, compare com o arquivo mestre privado no Alpha usando acesso autorizado.
3. Defina responsável, objetivo e critérios de aceite; preserve funcionalidades.
4. Não declare uma implementação ou teste como concluído sem evidências.
5. Não faça merge nem publicação por conta própria; registre riscos, resultados e pendências.

A sincronização configurada em `.github/workflows/sync-mk-protocol.yml` propõe atualizações por pull request, não executa merge automático.

**Aviso:** Estas instruções são lidas apenas por agentes/ferramentas compatíveis com `AGENTS.md`; outros agentes externos precisam ser configurados separadamente.
